How to update the data

Download the three CSVs. They hold everything currently on this board.

Make one Google Sheet with three tabs named exactly Tenders, Data and Actions, and import one CSV into each. Row 1 must stay as the headings.

Share it as Anyone with the link · Viewer, then paste the link into Connect sheet above.

Each week, add rows to Data and edit Actions. Nothing in this page needs editing.

To load it automatically for everyone, set CONFIG.SHEET_URL near the top of the script to your sheet link, then re-publish.

All weekly numbers go in one tab. Data is one row per figure, so a single Google Form can feed it:

ColumnWhat goes in it
cityAmritsar, Bathinda, Jalandhar, Ludhiana, Mohali, Patiala
streamISWM · Mech Sweeping Main Roads · Mech Sweeping Internal Roads · Litter Picker
packageContract or plant name — “41 Wards”, “North”, “Jagatpura Plant”. Leave blank if the city has only one.
sectionStatus · Daily · Machines · Processing Plant · Secondary Points · GVP · Patrol Teams · Points
metricThe row label — “B2B Rehri”, “Road Washer”, “Sweeping”, “Waste In”, “Clear”, “Model Town”
dateOnly for daily or weekly figures. Blank for standing parameters.
targetRequired or targeted. Blank if there is no target.
valueActual, achieved or current.
remarksFree text, shown beside the figure.

Bars and dials are computed from target and value. A section appears on a city page only when rows exist for it, so adding a new plant or package needs no code change.
